Atualizar base de veículos

Como este painel é publicado como arquivo estático, ele lê os dados de um arquivo data.xlsx (ou data.csv) publicado na mesma pasta do index.html, no seu host (Netlify, GitHub Pages, etc). Não há login nem planilha externa envolvida.

Para atualizar o painel para todo mundo que acessa o link:

  1. Edite normalmente a sua planilha Placas_BID2026
  2. Salve/exporte ela como data.xlsx (ou data.csv)
  3. Envie esse arquivo para a pasta do site no seu host, substituindo o antigo (mesmo nome)
  4. Pronto — quem abrir o link já vê os dados novos automaticamente

Colunas esperadas no data.xlsx/data.csv:

Placa SVC Implantação Regional Modal Locadora Modelo Cronograma Planejamento Previsão Final Entrega Entregue

Datas em DD/MM/AAAA, AAAA-MM-DD ou datas nativas da planilha. Deixe Entregue em branco enquanto o veículo não chegou.
